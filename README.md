# First PR Practice

A tiny practice repo for shiping your first pull request.

## What is this?

This repo exists so you can practice the full pull request workflow:
branching, commiting a change, pushing, and opening a PR on GitHub.

## Usage

1. Create a branch
2. Make a small change
3. Push and open a PR
4. Merge it!
